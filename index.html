About

SleepyBot v1.0 — educational AI robot dashboard.
Target hardware: ESP32-S3 N16R8 (16 MB flash, 8 MB OPI PSRAM).
The ESP32-S3 is the robot controller; heavy AI runs on a backend server. This frontend never touches an AI provider directly.
Currently running in simulation mode — no hardware required.
